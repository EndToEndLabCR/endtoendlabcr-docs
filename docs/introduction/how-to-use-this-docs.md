# How to Use These Docs

Quick guide to finding what you need without getting lost.

## 🗺️ What's Here

The docs are organized into eight sections:

| Section                     | What's Inside                                        |
| --------------------------- | ---------------------------------------------------- |
| **Introduction**            | Who we are, why we're here, how these docs work      |
| **Tech Stack**              | Guides for the tools and frameworks we use           |
| **Best Practices**          | Our standards for code, architecture, and workflows  |
| **Projects**                | Documentation for specific projects we're working on |
| **Guides & Tutorials**      | Step-by-step walkthroughs for common tasks           |
| **FAQ & Troubleshooting**   | Answers to questions we keep getting asked           |
| **Architecture & Patterns** | Design decisions and the reasoning behind them       |
| **Install & Setup**         | How to get your dev environment running              |

## 🎯 I Need...

**Quick paths based on what you're looking for:**

- _"I just joined — where do I start?"_ → Start with [What is EndToEndLabCR](./what-is-endtoendlabcr), then [Install & Setup](../category/install-and-setup)
- _"How do I set up my environment?"_ → Jump to [Install & Setup](../category/install-and-setup)
- _"What tech stack do we use?"_ → Head to [Tech Stack](../category/tech-stack)
- _"How do we structure our code?"_ → Check [Architecture & Patterns](../category/architecture-and-patterns)
- _"I'm stuck on something"_ → Try [FAQ & Troubleshooting](../category/faq-and-troubleshooting) first, then ask on [Discord](https://discord.gg/mAD7Y6fNzv)
- _"I want to contribute"_ → Read on — the section below is for you

## 💡 Tips for Getting the Most Out of These Docs

- **Use the search bar** — It's fast and usually finds what you need
- **Bookmark sections you use often** — You'll be back
- **Cross-links are your friend** — We link related topics so you don't have to hunt
- **Check the date** — If something feels outdated, it probably is. Update it or flag it

## 🤝 Contributing

These docs are a team effort. Here's how to pitch in:

1. **Spot a gap?** — Write about it. A rough draft is better than no draft
2. **Found an error?** — Fix it. Don't wait for someone else
3. **Have a better way?** — Update the doc and explain why in your PR
4. **Not sure where something goes?** — Put it somewhere reasonable and we'll sort it out in review

### Style Quick Guide

When writing or editing:

- **Be direct** — Write like you're explaining to a teammate
- **Show, don't tell** — Use code examples, not just descriptions
- **Keep it current** — Outdated docs mislead. Update or archive them
- **Link liberally** — Connect related topics so readers can explore

## 📬 Feedback

Something unclear? Missing info? Have a suggestion?

- **Quick fix** — Edit the doc directly and submit a PR
- **Bigger idea** — [Open an issue](https://github.com/EndToEndLabCR/endtoendlabcr-docs/issues) with your suggestion
- **Want to talk it through?** — Drop by [Discord](https://discord.gg/mAD7Y6fNzv) or ask at office hours
